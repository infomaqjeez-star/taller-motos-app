CATÁLOGO — carpetas locales sin usar npm
========================================

1) En esta misma carpeta hay GenerarCatalogo10.bat (10 productos) y
   GenerarCatalogoCompleto.bat (todo el PDF). Doble clic en uno.

2) Hace falta catalogo.pdf en:
   apps\taller-demo\scripts\catalogo.pdf
   o en apps\taller-demo\public\catalogo\catalogo.pdf

3) Las carpetas salen en:
   %USERPROFILE%\Documents\CatalogoKonectaArticulos\productos\

3b) Si usás "npm run catalogo:folders:10" y falla: hacé "git pull", o definí la variable
    de entorno de Windows PYTHON_EXE con la ruta completa a python.exe
    (ej. C:\Users\...\AppData\Local\Programs\Python\Python312\python.exe).

3c) Si el .bat dice que no encuentra Python:
   - Instalá Python 3 desde https://www.python.org/downloads/ y marcá "Add python.exe to PATH".
   - En Windows: Configuración → Aplicaciones → Configuración avanzada de aplicaciones
     → Alias de ejecución de aplicaciones → DESACTIVAR "python.exe" y "python3.exe"
     (son atajos a la Microsoft Store y suelen romper el comando "python").

4) Si NO ves estos archivos en el Explorador de Windows, tu clon está viejo.
   En la raíz del repo (donde está la carpeta .git):
     git fetch origin
     git checkout main
     git reset --hard origin/main

   (reset --hard borra cambios locales no guardados en esa carpeta.)

5) Los mismos .bat también están en apps\taller-demo\ (un nivel arriba de scripts).
