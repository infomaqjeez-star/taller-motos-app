PDF del catálogo (Konecta / desmalezadoras)
==========================================

Ubicación por defecto (cwd = apps/taller-demo, Windows):

  apps\taller-demo\scripts\Catalogo Abril 2026 Konecta Repuestos.pdf

Si el archivo tiene otro nombre, usá siempre --pdf "scripts\tu-archivo.pdf"

Opcional (para versionar aparte): también podés copiar una copia en
  data/catalogo-konecta-source/
y subirla con git (ojo tamaño; Git LFS si hace falta).

---
1) Dependencias base (extracción por SKU / carpetas):

   pip install -r scripts/catalogo/requirements.txt

2) Testeo extracción (tabla SKU / precio lista / ×4 / nombre; NO escribe JSON):

   python scripts/catalogo/extract_catalogo_pdf.py --pages 0 --max-skus 25 --report

   Con imágenes de prueba en public/catalogo/ (sin tocar JSON):

   python scripts/catalogo/extract_catalogo_pdf.py --pages 0 --max-skus 8 --report --report-save-images

2b) JSON + imágenes planas por SKU (480²), todo el PDF:

   python scripts/catalogo/extract_catalogo_pdf.py --pages all --format webp

   Solo página 0 escribiendo archivos:
   python scripts/catalogo/extract_catalogo_pdf.py --pages 0 --format webp

   Calibración recorte: --side-mult 6 --above-mult 28 --below-mult 8

3) Carpetas Maqjeez por artículo (450² centrada en SKU + meta.json precio×4):

   python scripts/catalogo/build_product_folders.py --pages 0 --limit 1
   python scripts/catalogo/build_product_folders.py --pages all --update-json

   Salida:
   public/catalogo/Catalogo-Abril-2026-Maqjeez-Repuestos/productos/<nombre>__<SKU>/

4) Pipeline OCR (rejilla 4×5, tapar precio viejo y escribir lista×4 en la imagen):

   pip install -r scripts/catalogo/requirements-catalog-ocr.txt
   + Tesseract instalado (Windows: set TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe)

   Dry-run página 0:
   python scripts/catalogo/catalog_grid_ocr_pipeline.py --out data/catalogo-ocr-export --pages 0 --dry-run

   Todas las páginas:
   python scripts/catalogo/catalog_grid_ocr_pipeline.py --out data/catalogo-ocr-export --pages all

   Ajustar grilla: --cols --rows --margin-x --margin-y
   Modo contornos: --mode contour

5) Commit (ajustá rutas según qué archivos generaste):

   git add data/catalogo-public.json public/catalogo/ data/catalogo-ocr-export/
   git commit -m "feat(catalogo): datos desde PDF"
   git push origin main
