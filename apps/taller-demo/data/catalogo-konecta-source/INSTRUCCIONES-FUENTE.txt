1) Colocá el PDF aquí como:
   catalogo-konecta.pdf

2) Subilo al remoto (desde la raíz del repo, carpeta taller-motos-app):
   git add apps/taller-demo/data/catalogo-konecta-source/
   git commit -m "chore(catalogo): agregar PDF fuente Konecta"
   git push origin main

3) Generar JSON + imágenes (en consola, cwd = apps/taller-demo):
   pip install -r scripts/catalogo/requirements.txt
   python scripts/catalogo/extract_catalogo_pdf.py --pdf data/catalogo-konecta-source/catalogo-konecta.pdf --pages all --format webp

   Prueba rápida (solo página 1):
   python scripts/catalogo/extract_catalogo_pdf.py --pages 0 --format webp

   Si el recorte no coincide con el PDF, calibrá:
   --side-mult 6 --above-mult 28 --below-mult 8

4) Commit de salida (JSON + public/catalogo/*.webp):
   git add data/catalogo-public.json public/catalogo/
   git commit -m "feat(catalogo): datos e imágenes desde PDF Konecta"
   git push origin main

PDF muy grande: Git LFS (git lfs track "*.pdf") antes del primer add del PDF.

--- Carpetas por artículo (Maqjeez, ~1300) ---

Directorio en disco (desde apps/taller-demo):
  public/catalogo/Catalogo-Abril-2026-Maqjeez-Repuestos/productos/<nombre-saneado>__<SKU>/
Cada carpeta: imagen.webp (450x450 centrada en el SKU) + meta.json (precioLista, precioVenta=lista×4).

Test solo el primer SKU de la página 0:
  python scripts/catalogo/build_product_folders.py --pages 0 --limit 1

Todo el PDF + actualizar imagen en catalogo-public.json:
  python scripts/catalogo/extract_catalogo_pdf.py --pages all --format webp
  python scripts/catalogo/build_product_folders.py --pages all --update-json

Ajustar zoom del recorte si la miniatura queda chica o grande: --half-side-mult 14 (default)

--- Pipeline OCR (rejilla 4x5, precio tapado y x4 en la imagen) ---

Dependencias extra:
  pip install -r scripts/catalogo/requirements-catalog-ocr.txt
  + instalar Tesseract OCR en el sistema.

Windows:
  set TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe

Probar OCR en la pagina 0 sin escribir archivos:
  python scripts/catalogo/catalog_grid_ocr_pipeline.py --pdf data/catalogo-konecta-source/catalogo-konecta.pdf --out data/catalogo-ocr-export --pages 0 --dry-run

Salida PNG por celda (ajustar --margin-x/--margin-y/--cols/--rows si la grilla no calza):
  python scripts/catalogo/catalog_grid_ocr_pipeline.py --pdf ... --out data/catalogo-ocr-export

Modo contornos (experimental, si no hay grilla fija):
  python scripts/catalogo/catalog_grid_ocr_pipeline.py --pdf ... --out ... --mode contour
